## 实现规则
- `hwid/allowlist.txt` 的全部有效 ID 编译进同一个内核。
- 优先读取 `androidboot.chipid`，回退到 `oplusboot.serialno`。
- 缺失或白名单外 HWID 会 early boot panic，1 秒后自动重启。
- 不使用 workflow HWID 输入，白名单文件是唯一允许设备来源。
